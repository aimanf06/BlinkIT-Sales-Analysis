# BlinkIT Sales Analysis

## Objective
Analyze BlinkIT sales data to identify business trends and performance metrics.

## Tools Used
- SQL Server

## KPIs Analyzed
- Total Sales
- Average Sales
- Customer Count
- Revenue Distribution

## Key Findings
- Identified top-performing outlet locations
- Analyzed customer satisfaction trends
- Found highest revenue-generating outlet types

## Skills Demonstrated
- SQL
- Aggregations
- Data Analysis
- KPI Development
